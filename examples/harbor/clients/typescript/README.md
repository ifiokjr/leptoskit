# harbour-client

A typed TypeScript client for the **Harbour 0.1.0** RPC, generated by `leptoskit rpc generate --target typescript`.

It has no dependencies and uses the platform `fetch`; the calls go to the same routes the app itself uses. The package ships TypeScript source (`index.ts`), which Deno, Bun, and TypeScript-aware bundlers load directly; for plain Node, compile it with `npx tsc -p .`.

## Usage

```ts
import { Client, FnError } from "harbour-client";

const api = new Client({ serverUrl: "https://harbour.example" });

try {
	const result = await api.bookSeat({ sailing: /* ... */ });
} catch (error) {
	if (error instanceof FnError && error.retryable) {
		// a network or server failure: safe to try again
	}
	throw error;
}
```

`Client` takes `serverUrl` (defaults to the page's own origin), `headers` sent with every request (for example `Authorization`), and a `fetch` implementation.

Errors are `FnError` instances with a `kind` of `network`, `invalid`, `server`, `decode`, or `other`, mirroring the server's classification; `retryable` is true only for `network`.
