# Share columns across tables with `#[db::mixin]`

Declare a set of columns once with `#[db::mixin]` and flatten it into any table with `#[db(flatten)]`, or `#[db(flatten, prefix = "billing_")]` to use it twice. The table gets the columns in place, along with the mixin's rules, indexes, and unique constraints. Public types nest each mixin's public type, and inserts take only what the database layer doesn't fill in. `db::Timestamps`, `db::SoftDelete` and `db::Versioned` come built in. `db::Versioned` adds optimistic concurrency: `save` refuses a row that changed since it was read, with `DbError::Stale`, and the new `#[db(version)]` marker does the same for any integer column.
