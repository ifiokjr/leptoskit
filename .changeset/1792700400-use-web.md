# Browser-only hooks behind the leptoskit_use web feature

`leptoskit_use` gains an optional `web` feature that compiles a `leptoskit_use::web` module on browser targets only: `use_event_listener` for DOM events, `use_media_query` for CSS media queries, and the `use_preferred_dark` and `use_preferred_reduced_motion` settings hooks. Listeners are scoped to the reactive owner and also stop through a returned handle; without a window, or for rejected queries, media signals stay `false`. Enabling `leptoskit`'s `web` feature turns the module on wherever `leptoskit::use` is enabled, so web builds pick it up automatically while native guests never compile it.
