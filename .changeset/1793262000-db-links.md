# Follow links between tables

Every `Id<T>` column now gets two methods: an accessor that loads the row it points at, so `author_id` gives `post.author(&db)` (`Option<T>` for an optional link), and a `Post::by_author(id)` query. `#[db(backlink = posts)]` adds the reverse to the linked table: `user.posts()` returns a query that filters, orders, and counts like any other. Tables keyed by `Id<Self>` implement the new `HasId` trait.
