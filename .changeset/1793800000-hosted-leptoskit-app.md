# Add the hosted LeptosKit app and dedicated workers

Add a shared web/iOS/Android management app, tenant-scoped hosted API and journals, operator-enrolled accounts, Stripe Checkout/portal integration with signed and deduplicated subscription updates, one-use worker pairing, scoped CLI keys and encrypted versioned OpenTofu HTTP state with locking. Dedicated outbound workers reuse the existing release engine and preserve uncertain operations for reconciliation. Support customer-owned infrastructure and approved operator-provisioned DigitalOcean installations without sharing customer execution environments.
