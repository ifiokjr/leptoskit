# Declare custom scalars with `#[derive(db::Scalar)]`

A newtype such as `struct Handle(String)` with `#[db(min_len = 4, max_len = 20, regex = "...", normalize(trim, lowercase))]` is now valid by construction. `Handle::parse` normalizes and checks it, `Deserialize` goes through `parse`, its JSON Schema carries the rules, and every column of its type gets them as database checks. Number scalars take `min` and `max`. `Email`, `Url` and `Slug` come built in.
