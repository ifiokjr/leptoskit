# The DevTools interface

`leptoskit dev`'s hub now serves the DevTools interface, a leptoskit app in `devtools/`: sessions grouped by app, a searchable element tree with picking, a node's source with "open in editor", its frame on every platform the app runs on, its classes (editable) and their declarations, the route, queries, mutations, forms, named state, calls, and commits. The hub serves a local build named by `LEPTOSKIT_DEVTOOLS_UI`, or the build downloaded for the CLI's version, and otherwise its plain page with a note on how to get the interface. Native snapshots now carry each node's classes and their declarations, and the hub streams sessions opening and closing.
